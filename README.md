# Yume Haze Zapret 2.1.3

Полноценное Windows-приложение (Electron) — графическая оболочка для **Zapret**
([Flowseal/zapret-discord-youtube 1.10.4](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.4))
и **TG WS Proxy** ([Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy/releases)).
Интерфейс полностью повторяет присланный макет: обзор с «орбом» питания, страницы Zapret/TG WS Proxy,
тесты, автоподбор, обновления, журнал, настройки, «О программе» — и всё это работает, а не рисует заглушки.

---

## 1. Быстрый старт (из исходников)

Нужен только [Node.js 18+](https://nodejs.org).

```bash
cd yume-haze
npm install
npm start
```

> Для перехвата трафика `winws.exe` нужны **права администратора** — запускайте
> терминал «от имени администратора» (или собранный `.exe` с ПКМ → «Запуск от имени администратора»).

При первом запуске компоненты не установлены — откройте **Обновления → Установить**
(скачаются `zapret-discord-youtube-1.10.4.zip` и `TgWsProxy_windows.exe`).

## 2. Готовые сборки

Установщик собирается локально командой `npm run dist:nsis` → `release/YumeHazeZapret-<версия>-setup.exe`
(NSIS, x64, ~81 МБ).

Готовый файл текущей версии — в разделе [Releases](https://github.com/NobuCraft/yume-haze-zapret/releases/latest).

Сообщество: [Discord](https://discord.gg/qHabsmgKVP) · [GitHub](https://github.com/NobuCraft/yume-haze-zapret)

Установщик ставится по-пользовательски (без UAC), создаёт ярлыки на рабочем столе и в меню «Пуск»,
удаляется через «Приложения и возможности». Для боевого режима запускайте ярлык
**от имени администратора** — иначе `winws.exe` не сможет загрузить драйвер.

Смартфон-антивирусы и SmartScreen могут ругаться на неподписанный exe — сборка без
сертификата кода, это нормально: «Подробнее → Выполнить в любом случае».

## 3. Что реально делает программа

### Установка и обновление компонентов
* Скачивает релиз Zapret `1.10.4` с GitHub, распаковывает в
  `%APPDATA%\Yume Haze Zapret\zapret`, сохраняет пользовательские списки.
* Скачивает актуальный `TgWsProxy_windows.exe` (GitHub API `/releases/latest`).
* Проверка обновлений: Zapret (`releases?per_page=15`), TG WS Proxy, кэш 6 часов,
  сравнение версий, «Что нового» из release notes, зеркала (`gh-proxy.com`, `ghfast.top`)
  на случай блокировки GitHub.
* Обновление `ipset-all.txt` и проверка `hosts` из `.service` репозитория zapret.

### Zapret
| Кнопка / раздел | Что происходит на самом деле |
|---|---|
| Большой тумблер, «Перезапуск» | `taskkill winws.exe` → проверка драйвера (при `not-installed` служба WinDivert создаётся автоматически) → **прямой запуск `winws.exe`** с аргументами из выбранного `.bat` (переменные `%BIN%`, `%LISTS%`, `%GameFilterTCP/UDP%` раскрываются в приложении) → вывод ошибок читается из stdout/stderr и попадает в журнал |
| «Проверить запуск» (вкладка «Драйвер») | запускает стратегию и показывает причину падения человеческим языком: драйвер WinDivert, отказ в правах, занятый драйвер, неверный параметр, отсутствующий `.bin` |
| Битый драйвер | если служба `WinDivert` есть, но не запускается (типично «ошибка 123» после прежних попыток), она **пересоздаётся** с корректным `binPath`; вывод `sc.exe` перекодируется из cp866, коды 123/2/5/87 расшифровываются |
| Резервный запуск | когда прямой запуск `winws.exe` не открывает драйвер, стратегия запускается штатно через свой `.bat` (`cmd /c call <стратегия>.bat`) — так же, как это делает оригинальный Zapret |
| Разбор аргументов | строка из `.bat` токенизируется как в `cmd.exe` (кавычки группируют, но в аргументы не попадают) — иначе `winws.exe` съедал `--wf-tcp` и падал с `must specify port`; недостающие `lists\*.txt` досоздаются автоматически |
| Проверка перед запуском | состояние службы WinDivert, права, конфликтующие обходы (GoodbyeDPI, Happ, v2ray, xray, Clash, WireGuard), политика блокировки уязвимых драйверов |
| Список стратегий (22 шт.) | реальные файлы релиза 1.10.4 (`general.bat`, `ALT…ALT13`, `EXP`, `FAKE TLS AUTO…`, `SIMPLE FAKE…`); выбор применяется и при работающем обходе выполняется перезапуск |
| Игровой фильтр | пишет `utils\game_filter.enabled` в формате `service.bat` (`mode/tcp/udp`) и перезапускает Zapret — порты попадают в `--wf-tcp/--wf-udp` |
| IPset (по списку / любой IP / выключен) | как в `service.bat`: список + `.backup`, строка `203.0.113.113/32` (none) или пустой файл (any) |
| Списки доменов | пишет `lists\list-general-user.txt`, `list-exclude-user.txt`, `ipset-exclude-user.txt` (CRLF) |
| Установить / удалить службу | разбирает аргументы `.bat`, подставляет `%BIN%`, `%LISTS%`, `%GameFilterTCP/UDP%`, вызывает `sc create/start/delete` (+ уборка `WinDivert`) |
| Очистить кэш Discord | закрывает Discord/PTB/Canary, удаляет `Cache`, `Code Cache`, `GPUCache` |
| Драйвер (вкладка «Zapret → Драйвер» и карточка в «Обновлениях» рядом с Zapret/TG) | состояние службы `WinDivert`, наличие и версия `bin\WinDivert64.sys` / `WinDivert.dll`, подпись через `Get-AuthenticodeSignature`, кнопки «Установить драйвер» (`sc create WinDivert type= kernel`), «Удалить службу», расшифровка кодов ошибок загрузки (577, 1275, 1793, 1058) |
| Диагностика | права администратора, наличие `bin\winws.exe`/`WinDivert64.sys`, процесс, служба, конфликты (GoodbyeDPI, Happ, v2ray, xray, clash, WireGuard…), IPset, TCP timestamps, пинг DC Telegram |

### TG WS Proxy
* Запуск `TgWsProxy.exe --host … --port 1443 --secret <32hex> --pool-size 4 --dc-ip 2:… --dc-ip 4:… --portable`
  (+ `--no-cfproxy`, `--no-h2`, `--no-secure`, `--fake-tls-domain`, `--cfproxy-domain`, `--verbose`).
* Ссылка `tg://proxy?server=…&port=…&secret=dd<secret>` (при Fake TLS — `ee<secret><hex домена>`,
  как в `utils/tray_common.py`), QR-код, кнопка «Подключить в Telegram».
* Живая статистика из строк `stats: total=… active=… up=…/down=…`, пинг DC1–DC5, новый секрет,
  горячее применение параметров (прокси перезапускается).
* Проверка занятости порта, авто-перезапуск при смене настроек, портативный режим (`TgWsProxy_data`).

### Тесты
* **Быстрый тест**: 12 целей (Discord, YouTube, Google, Cloudflare) + TCP-пинг 1.1.1.1/8.8.8.8,
  оценка 0–100 с учётом задержек, история (40 прогонов).
* **Автоподбор**: последовательно запускает выбранные стратегии, тестирует каждую,
  сортирует результаты, применяет лучшую и запускает Zapret; кнопка «Стоп», прогресс,
  баннер с победителем, «Быстрый/Полный» режим; результат сохраняется в историю.
* **История**: вернуть любую ранее проверенную стратегию одним нажатием.
* **Диагностика**: см. выше (Zapret + прокси).

### Драйвер WinDivert
**Драйвер не принадлежит приложению.** `WinDivert64.sys` и `WinDivert.dll` приходят
в самом архиве Zapret от Flowseal (`bin\`) и обновляются вместе с ним. Приложение
их не скачивает, не вшивает в установщик и не подменяет — только показывает состояние
и умеет убрать мешающую службу.

**Службу создавать не нужно.** `winws.exe` сам загружает `WinDivert64.sys` из своей папки
и регистрирует драйвер в системе. Именно вручную созданная служба с неверным `binPath`
и давала ошибку `123 — неправильный синтаксис имени файла`, из-за которой `winws.exe`
завершался сразу после старта. Поэтому кнопка «Проверить драйвер» только:
убирает чужие/битые службы `WinDivert`/`WinDivert14`, запускает `winws.exe` с аргументами
текущей стратегии и смотрит, живёт ли процесс.

Если ошибка 123 всё же появилась — кнопка **«Убрать службу и перезапустить»**
(вкладка *Zapret → Драйвер*): служба удаляется, драйвер загружает сам `winws.exe`,
стратегия запускается сразу же.

Состояние `not-installed` — **нормальное**: файлы драйвера на месте, отдельной службы нет.
Ошибки загрузки расшифровываются в журнале: 123 (кривая служба), 1275 (блокировка уязвимых
драйверов после обновления Windows), 577/1793 (подпись), 1058/1077 (тип запуска).

### Обновления с GitHub
Zapret (`Flowseal/zapret-discord-youtube`) и TG WS Proxy (`Flowseal/tg-ws-proxy`)
скачиваются с GitHub и обновляются оттуда же — вшитых копий в установщике нет,
так что новые версии Flowseal подхватываются кнопкой «Обновить» в разделе «Обновления».

### Режим «без драйвера» (через службу Windows)
Если Windows не даёт загрузить драйвер обычным путём: кнопка **«Через службу Windows»**
на вкладке *Драйвер*. Приложение повторяет действия оригинального `service.bat install`,
но без консольных окон: создаёт службу `zapret` с полной строкой аргументов стратегии
и запускает её — `winws.exe` под SYSTEM сам поднимает драйвер.

Полностью отказаться от WinDivert нельзя: без него `winws.exe` не перехватывает трафик.
Варианты без Zapret — встроенный **TG WS Proxy** (вкладка *TG WS Proxy*) или системный VPN.

### Права администратора (UAC)
* При старте приложение проверяет права (`net session` + роль в токене через PowerShell).
* Если прав нет — наверху окна висит баннер **«Нужны права администратора»** с кнопкой
  «Перезапустить с правами».
* Любая попытка включить Zapret без прав не приводит к писку Windows: показывается диалог,
  при согласии приложение перезапускается через `Start-Process -Verb RunAs` (UAC) и
  **сразу выполняет то же действие** — команда передаётся новому экземпляру (`yh-zapret://start|toggle|restart`).
* Отказ в UAC или его отсутствие (групповые политики) не ломают приложение — просто возвращается ошибка.
* Автозапуск с Windows настраивается задачей Планировщика с флагом `/RL HIGHEST`, поэтому
  при входе в систему обход стартует сразу с правами, без окна UAC.
* Трей и автозапуск служб используют те же правила повышения.

### Системная часть
* Трей: включить/остановить Zapret и прокси, копировать ссылку, быстрая проверка, журнал, выход.
* Закрытие в трей, запуск с Windows (`app.setLoginItemSettings`), старт свёрнутым, уведомления.
* Журнал: источники APP / ZAPRET / TG / TEST / NET / UPD / ERR, фильтры, поиск, копирование,
  файл `%APPDATA%\Yume Haze Zapret\logs\app.log` с ротацией.
* Настройки: акцентный цвет, анимации, пути к уже распакованному Zapret/`TgWsProxy.exe`,
  автообновления, зеркало GitHub, сброс.
* Один экземпляр приложения, кастомный титлбар (свернуть/развернуть/закрыть).

## 4. Структура проекта

```
yume-haze/
├─ main.js                 главный процесс: окно, трей, IPC, автозапуск, состояние
├─ preload.js              contextBridge → window.api (без nodeIntegration)
├─ src/
│  ├─ config.js            настройки по умолчанию, patch/reset, пути
│  ├─ logger.js            журнал: буфер + файл + подписка UI
│  ├─ util.js              HTTP с зеркалами, процессы, sc, tcpProbe, freePort, admin
│  ├─ unzip.js             встроенный ZIP-распаковщик (store/deflate), без PowerShell
│  ├─ zapret.js            установка, запуск, списки, IPset, служба, диагностика
│  ├─ tgws.js              установка, аргументы, ссылки, статистика, DC-пинг
│  ├─ net.js               тесты доступности, автоподбор, история
│  ├─ updates.js           проверка/установка обновлений
│  └─ assets/strategies.js 22 стратегии релиза 1.10.4 с описаниями
├─ renderer/
│  ├─ index.html           весь интерфейс макета + стили (self-contained)
│  ├─ app.js               логика UI, QR, рендер состояния, диалоги
│  └─ assets/              qrcode.js (MIT, Kazuhiko Arase), tray.png, logo.png
├─ res/icon.ico            иконка приложения (папка build/ не сохраняется в снапшотах)
├─ scripts/selftest.js     45 автотестов логики (node scripts/selftest.js)
├─ scripts/ui-check.py     smoke-тест интерфейса в headless Chromium (Playwright)
├─ scripts/gen_assets.py   генерация иконок
└─ tests/fixtures/zapret/  настоящие general.bat/service.bat из релиза 1.10.4
```

## 5. Проверки

```bash
node scripts/selftest.js && node scripts/elevation-test.js && node scripts/spawn-test.js
```
45 тестов: разбор аргументов `general.bat` (в т.ч. подстановка игрового фильтра), формат
`game_filter.enabled`, режимы IPset, roundtrip списков, ссылки `dd`/`ee`, флаги CLI прокси,
разбор строки `stats:`, оценка доступности, сравнение версий, наличие всех элементов макета
и соответствие вызовов UI ↔ IPC ↔ preload.
Плюс 17 тестов запуска `winws.exe` (импорт `sc`, путь без кавычек для `spawn`,
отсутствие `.bin`/`winws.exe`, разбор вывода, IPC-каналы драйвера) и 8 тестов повышения прав: код `ELEVATION_REQUIRED`, отмена в UAC, защита от повторных
окон, неинтерактивный автозапуск, разбор отложенной команды `yh-zapret://…`.

```bash
python3 scripts/ui-check.py      # требует pip install playwright && playwright install chromium
```
Проходит по всем экранам, кликает кнопки и сохраняет скриншоты в папку `shots/` рядом с проектом.

Дополнительно проверено при разработке (в Linux-песочнице):
* полный цикл установки Zapret — скачивание релиза 1.10.4, распаковка, раскладка,
  создание списков, разбор аргументов **всех 22** `.bat` (переменные `%BIN%`, `%LISTS%`,
  `%GameFilterTCP/UDP%` и экранирование `^!` раскрываются правильно);
* скачивание `TgWsProxy_windows.exe` (20.8 МБ, валидный PE-файл);
* запуск настоящего Electron: окно создаётся, IPC работает, рендер строит 22 карточки стратегий,
  QR-код генерируется, запросы доступности и диагностика выполняются без ошибок в консоли.

## 6. Важные замечания

* Windows 10/11 x64. Запуск **от имени администратора** обязателен для `winws.exe` (WinDivert).
* Если служба `zapret` установлена, ручной запуск стратегий блокируется — так же ведёт себя
  оригинальный `service.bat`; удалите службу кнопкой «Удалить службу».
* Одновременная работа GoodbyeDPI/Happ/v2ray ломает обход — диагностика это покажет.
* Данные (настройки, компоненты, логи) — в `%APPDATA%\Yume Haze Zapret`.
* Проект — оболочка: сами `zapret` и `tg-ws-proxy` распространяются под своими лицензиями
  (см. LICENSE.txt в архиве zapret и LICENSE в tg-ws-proxy).
